## v0.8.0

设置页交互与操作效率跃升：状态筛选标签、紧凑与卡片双视图模式、双列表单排版、一键批量并发测速排查、结果一键复制与提示文字视觉高亮。
无 schema 变更，0.7.0 配置无需迁移。

### 改了什么

- **状态快速筛选标签 (Filter Chips)。** 在搜索过滤框上方增加状态标签：`全部`、`走代理`、`直连`、`配置被拒`，各自附带实时计数值，可按网络路由状态快速过滤卡片。
- **紧凑列表视图 (Compact View)。** 页面右上角增加视图切换，支持在「卡片视图」与「紧凑视图」间无缝切换。紧凑模式下每行紧凑展示 Provider 开关、名称、端点类型、状态 Pill 与时延，并支持单行独立测试与展开编辑。
- **双列表单排版 (Two-column Grid)。** 卡片内端点输入重组为响应式双列网格，大幅减少纵向空白，单张卡片高度压降 40% 以上。
- **一键批量测速排查 (Batch Self-Check)。** 顶部操作栏提供「测试已启用 (N)」按钮，采用最大并发数 3 的并发限流池顺序执行自检，实时展示测试进度，避免高并发挤占本地代理端口。
- **出口 IP / 错误信息一键复制 (Quick Copy)。** 自检成功回显的出口 IP、自检目标 URL 及错误信息旁增加一键复制按钮，带「已复制」即时轻量反馈。
- **提示文字视觉着色高亮 (Hint Styling)。** 表单与全局设置中的辅助提示文字（如 IP/主机粘贴支持提示、认证口令说明、SOCKS5 隧道提示等）统一赋予 `state-warn-primary` 暖色高亮及可靠回退色，显著提升表单可读性，与常规灰色标签形成清晰视觉层级。

### 行为变化

- 状态筛选和视图切换仅为当前界面视图状态，不写任何设置文件，刷新后保持安全默认。
- 批量测速复用现有的 Host `/test` 端点与 3 秒冷却规则。
- 0.7.0 配置文件直接兼容，无任何 schema 破坏。

### 验证

- `npm run verify`：280 个用例全绿通过（基线 274 + 新增 6 个集成测试）。
- 新增覆盖：状态筛选 Chip 计算与过滤断言、紧凑/详细视图模式切换与展开交互断言、默认代理与卡片表单双列网格断言、批量测速限流并发与进度断言、一键复制剪贴板反馈断言、表单提示文字高亮色与回退色样式断言。

### 升级

无字段迁移。0.7.0 的 `cordis.patch.yml` 可直接使用。
