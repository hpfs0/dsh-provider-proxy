## v1.3.0 (Backup & Observability)

备份与可观测性版本：让「恢复＝整体替换」真正覆盖全部全局开关，并把仪表盘口径、英文界面、页签键盘导航与目录缺失 provider 的处理拉回一致。

基于 `v1.2.0` 基线，备份文档从 `version: 2` 升级到 `version: 3`（新增 `enableFallbackDirect`），minor 级发布。

### 修复

- **备份升级为 Schema v3（P3）。** `BACKUP_VERSION` 2 → 3；导出文件新增顶层 `enableFallbackDirect`（默认 `false`），并在一次原子恢复写入里与其余十段配置一起替换。旧版文件（无 version / 1 / 2）仍可导入，缺失的新字段按安全默认值 `false` 补齐；来自更新版本的文件（version > 3）明确拒绝。密码脱敏范围不变，新字段不携带凭据。
- **仪表盘口径与文档对齐（P3）。** 成功率与平均延迟统一为近 24 小时窗口，并纳入真实请求、手动自检与心跳探针的完成结果；在途请求、pending 自检和过期样本不参与统计，空样本仍显示 `100% 成功`，未测延迟显示 `- ms`。
- **英文界面不再残留中文（P3）。** 侧栏导航项与页签标签走同一份 locale 字典，保存提示改为字典前缀；补齐新增字典键的 EN/ZH 对应项。
- **页签补齐键盘导航（P3）。** 使用 roving tabindex，仅当前页签在 Tab 序列中；左右方向键、Home / End 可以移动并切换页签，焦点行为与 ARIA tablist 语义一致。
- **批量测试计数与执行同源（P3）。** 「测试已启用 (N)」改为使用与批量执行完全相同的可用 enabled 集合，拒绝/半填端点不会既被计数又被错误执行。
- **旁路下的搜索预览不再误报（P3）。** 全局紧急旁路开启时，失效的搜索预设不参与 `role="alert"`；解析文案仍明确显示搜索一律直连。
- **空 `testUrl` 不再标红（P3）。** 留空是合法状态，显示普通提示；只有非法候选或超过 5 项才使用错误色。
- **目录轮询可自愈（P3）。** 临时失败读出不再关闭轮询定时器；服务恢复后的下一次 tick 会刷新目录并把结果送回页面。
- **目录缺失的已保存 provider 可见（P3）。** 目录加载成功但配置里仍存在的 provider 现在渲染为只读「目录中缺失」卡片，带关闭与删除入口，不提供启用开关；原连接诊断文字保留。
- **代码卫生（P3）。** 移除 `routeFingerprint` 的 `bypassAll` 死参数、死变量与冗余 `peerDependenciesMeta`。

### 行为变化

- **备份文件变为 `version: 3`。** 这是最需要注意的变化：1.2.x 及更早版本会明确拒绝 v3 文件。降级前请先在当前版本导出一份 v2 兼容文件，再用旧版本导入；不要依赖旧版直接读取新版文件。
- **成功率与延迟可能相对上一版跳变。** 之前是历史累计口径，现在只看近 24 小时且纳入自检 / 心跳结果；这是有意的口径修正，页面颜色语义不变。
- **目录缺失的已保存 provider 现在会出现在列表顶部的只读卡片里**，不再只躺在诊断文字中。卡片明确说明它「未启用」，不会误表现为可激活路由。

### 验证与质量

- `npm run verify`：**521 个用例全绿**（v1.2.0 的 507 个 + 14 个新增回归用例），`typecheck` 0 错误，构建通过。
- 每条修复都先有失败用例：备份跨版本矩阵、24h 口径、EN 导航与保存提示、页签键盘导航、批量计数与执行一致、旁路告警、空 `testUrl`、目录缺失只读卡、失败轮询自愈。
- Schema v3 验收矩阵覆盖：无 version / v1 / v2 导入补齐、v3 往返一致、手写 v3 文件导入、`version > 3` 拒绝、错误类型拒绝、密码脱敏不变。
- `npm pack --dry-run`：仍为 **9 个文件**，包内容清单未变。

### 升级与迁移

1. 升级前建议在桌面版或 `dsh web` 的备份页先导出一份现有 `version: 2` 文件。
2. 升级到 v1.3.0 后导出文件即为 `version: 3`，包含 `enableFallbackDirect`；旧文件导入后该字段按 `false` 处理，恢复仍是一次整体替换。
3. **如需降级到 1.2.x 或更早版本，请先导出一份 v2 兼容备份**，否则新版备份会被旧版拒绝；不要直接把 v3 文件交给旧版导入。

### 安装

桌面版（先完整打开一次桌面版以初始化 profile，再完全退出）：
```sh
dsh plugin --profile desktop add dsh-provider-proxy
```

Web 版：
```sh
dsh plugin --profile web add dsh-provider-proxy
```
