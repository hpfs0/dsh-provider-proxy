## v1.0.0 (GA)

生产级治理与稳定里程碑（Production-Ready GA）：故障容灾自动降级 (Failover)、运行监控仪表盘 (Dashboard Header)、全局紧急旁路 (Emergency Bypass All)、DSH 原生设计规范深度对齐与全方位无障碍 (a11y)。

基于 `v0.9.0` 基线，全量兼容 0.8.0/0.9.0 配置，无需字段迁移。标志着 `dsh-provider-proxy` 从「网络设置插件」升华成为生产级「LLM 代理治理中枢」。

### 改了什么

- **故障容灾自动降级策略 (N18)。**
  新增全局设置项 `enableFallbackDirect`（默认严格保持为 `false`，遵循安全 fail-closed 准则）。
  在网络抖动、本地代理服务崩溃或休眠唤醒（`ECONNREFUSED`、`ETIMEDOUT`、`EHOSTUNREACH` 等网络级中断）时，若已开启自动降级，插件会拦截异常并自动通过宿主原生网络重试请求，保障无人值守对话与长会话不被中断；在「最近调用」中以醒目告警色标明 `[降级直连]`。开启该开关时前端会展示显式的安全提示框（告知可能会向目标服务暴露本机真实出口 IP）。
- **运行监控仪表盘 (N19)。**
  在页面顶部新增常驻的运行监控仪表盘条目（Dashboard Grid），聚合呈现整机全局网络态势：
  - **代理覆盖率**：实时统计 `X / Y 活跃`（结合 live 状态与草稿实时联动响应，搭配矢量呼吸状态指示灯）。
  - **连通成功率**：基于近 24 小时内记录计算成功百分比（如 `100% 成功` / `链路状态健康`）。
  - **近期平均延迟**：基于近几次连接测试与自检统计加权时延（如 `- ms` / `260 ms` / `连通响应迅速`）。
  - **累计转发请求量**：千分符格式化展示全量请求累计数（如 `12,450`），并在数字右侧提供就地「重置」按钮（调用 Host `/dsh-provider-proxy/reset-hits` 清零计数）。
- **全局紧急旁路模式 (N20)。**
  仪表盘右上角集成「全局紧急旁路 (Bypass All)」快捷总控开关：
  - 开启时，所有 Provider 的网络请求瞬间全量走直连，页面顶部悬挂警示条；
  - **不改写任何 Provider 的个体设置**（各个卡片的代理开关、端点和规则完整保留）；
  - 关闭旁路时，瞬间恢复原有配置。极大降低了排查网络问题时逐卡关闭再逐卡开启的运维成本。
- **DSH 设计规范深度对齐、无障碍 (a11y) 与样式加固 (N21)。**
  - **规范对齐**：全面对齐 DSH Desktop 最新设计 Token 表（`--dsw-alias-*`），统一深浅色背景层级、边框色与高对比度文字色；
  - **矢量呼吸指示灯**：采用纯数学矢量 SVG 双层同心圆（实体核 + 半透明外晕），彻底解决 WebView 在不同 DPI/缩放下的椭圆变形问题；
  - **排版微调**：统一覆盖率文案为单行无折行格式，累计转发请求量的重置按钮放置于数字右侧，保证各卡片节奏齐整；
  - **无障碍支持**：所有开关补齐 `role="switch"` 与 `aria-checked`，按钮配备 `aria-label` / `aria-pressed`，告警栏配置 `role="alert"`；
  - **样式注入加固**：构建脚本增加类名数字前缀 CSS 选择器转义，同时配备完善的内联防御样式，杜绝任何外部样式表载入异常导致的破版。

### 行为变化

- **严格的 Fail-closed 默认原则保持不变**：`enableFallbackDirect` 默认恒为 `false`，绝不擅自暴露用户出口 IP。
- **实时响应的乐观统计**：覆盖率计算接入前端 React `draft` 草稿管道，勾选或取消代理即时响应数字变动，无需切页或等待落盘刷新。
- **旁路不破坏持久化状态**：`bypassAll` 为纯路由层短路，不污染卡片自身的持久化配置。

### 验证与质量

- `npm run verify`：全部 **410 个用例全绿通过**（覆盖故障模拟降级、fail-closed 断言、仪表盘四项指标统计、旁路路由短路断言、重置计数接口、实时草稿覆盖率联动、ARIA 无障碍属性等）。
- `npm run typecheck`：TypeScript 0 错误。
- `npm pack --dry-run`：零外置运行时框架依赖，打包体积极小，秒级加载。

### 升级与迁移

无需迁移。`cordis.patch.yml` 会自动按 Schema 默认值补齐 `enableFallbackDirect: false` 与 `bypassAll: false`。0.8.0/0.9.0 既有配置原样开箱即用。

### 安装

桌面版：
```sh
dsh plugin --profile desktop add dsh-provider-proxy
```

Web 版：
```sh
dsh plugin --profile web add dsh-provider-proxy
```
